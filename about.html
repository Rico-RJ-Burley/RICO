About This Project

This website is my research project for IT 3203 at Kennesaw State University. The topic is web servers: the computers and programs that deliver every website on the internet. I chose this topic because it connects my cybersecurity concentration to something I use every day, from loading a game’s website to streaming online.

The site is built with plain HTML and one CSS file, and it is hosted on GitHub Pages, which is itself a static web server. More research and content will be added in the next two milestones.
